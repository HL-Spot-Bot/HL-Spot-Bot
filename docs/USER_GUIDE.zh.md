# HL-Spot — 用户指南

版本 1.0.2

HL-Spot 是一款用于 **Hyperliquid** 的交易机器人：支持 spot 和永续合约（perp）市场、多个交易对、自动和手动下单。它运行**在您自己的电脑上**（Windows、Linux 或 Docker），您可以通过网页浏览器对其进行控制。

> **网站**：https://hlspot.com
> **下载**：https://github.com/HL-Spot-Bot/HL-Spot-Bot
> **支持**：HL-spot@cmails.eu

---

## 1. 开始之前

您需要：

- 一台搭载 64 位 x86 处理器（x86_64）并运行 **Windows** 或 **Linux** 的电脑，或任何装有 **Docker** 的机器；
- 或者一个 **Flux** 账户，以便在云端运行（第 16 节）；
- 一个有资金的 **Hyperliquid** 账户（您的主 wallet）；
- 一个能够用您的主 wallet 地址“**签名消息**”的 wallet。浏览器扩展（MetaMask、Rabby…）最为简单：机器人会为您打开它。其他任何 wallet 也可以通过复制粘贴的方式使用；
- 互联网连接。

## 2. 安全：您必须了解的事项

- HL-Spot 只接受 Hyperliquid 的 **API wallet** 密钥。**切勿输入您主 wallet 的私钥。** API wallet 可以代您交易，但无法提取您的资金。
- API wallet 密钥在您的电脑上是**加密**存储的。它**绝不会被发送**到许可证服务器。
- 您的主 wallet 仅用于**签名消息**（创建账户、忘记密码、BTC 地址、删除账户）。签名消息不是交易：它不产生任何费用，也不会转移任何资金。
- 机器人的网页受您的密码保护。建议在机器人所在的机器上使用（`http://localhost:60000`）：从您网络中的其他机器访问时，页面是不加密的（见第 15 节）。

## 3. 创建您的 Hyperliquid API wallet

1. 前往 **https://app.hyperliquid.xyz/API** 并连接您的主 wallet。
2. 为 API wallet 命名，然后生成它。
3. **复制显示的私钥**并妥善保管：Hyperliquid 只显示一次。
4. 授权该 API wallet（使用您的主 wallet 签名）。
5. 记下 Hyperliquid 显示的 API wallet **到期日期**。

您将在 HL-Spot 中输入：您的**主 wallet 地址**（0x…）和 **API wallet 私钥**。

## 4. 安装 HL-Spot

从 https://github.com/HL-Spot-Bot/HL-Spot-Bot 下载适用于您系统的文件及其 `.sha256` 文件。`.sha256` 文件可用于检查下载的文件是否完整。

### Windows

1. 解压 `HL-Spot-1.0.2-prod-windows-x64.zip`。
2. 在解压后的文件夹中，运行 **`HL-Spot.exe`**。会打开一个控制台窗口：在机器人运行期间请保持其打开。
3. 在浏览器中打开 **http://localhost:60000**。

### Linux（Ubuntu 22.04、24.04、26.04、Debian 12 或更新版本）

```
unzip HL-Spot-1.0.2-prod-linux-x64.zip
cd HL-Spot-1.0.2-prod-linux-x64
./hl-spot
```

然后在浏览器中打开 **http://localhost:60000**。

### Docker

```
docker load -i HL-Spot-1.0.2-prod-docker-x64.tar.gz
docker run -d --name hl-spot --restart unless-stopped -p 60000:60000 \
       -e TZ=Europe/Paris -v hl-spot-data:/data hl-spot:1.0.2
```

- `-p 60000:60000` 是访问网页所必需的。
- `TZ` 设置时区（省略时为 UTC）。
- 您的数据保存在 `hl-spot-data` 卷中，即使删除容器或更新镜像也不会丢失。
- `docker stop hl-spot` 可以干净地停止机器人。

然后打开 **http://localhost:60000**（或 `http://<machine address>:60000`）。

- 如果您是新用户，选择**创建账户**；

1. **钱包地址**：您的主 wallet 地址（0x…）。
2. **API wallet 私钥**：第 3 节中复制的密钥。系统会先通过 Hyperliquid 对其进行验证。
3. **密码**：至少 8 个字符，包含一个大写字母、一个小写字母、一个数字和一个特殊字符。它同时保护您的 HL-Spot 账户和机器人的网页。
4. **主钱包签名**：
   - **用我的钱包签名**：机器人会打开您的 wallet 扩展；请核对地址并确认签名；

5. 点击**创建账户**。

您的 **7 天免费试用**随即开始。每个 wallet、每次安装仅授予一次。您的 Hyperliquid 账户验证通过后即开始交易。

### 我已有账户

输入您的钱包地址和密码。本次安装将被注册，之前的安装将被释放（**每 30 天只能更换一次安装**）。

顶部菜单可访问以下页面：

只有在**您的 Hyperliquid 账户已验证**且**您的许可证有效**时，机器人才会进行交易。没有有效许可证时，只能使用 Hyperliquid 账户和许可证页面。

当机器人停止交易时（许可证到期、API wallet 过期或被拒绝），它**不会处理已经挂出的订单和已开的仓位**：这些由您自行负责。

以下小节先说明机器人如何做出决策，然后逐一介绍**交易中的交易对**和**设置**页面的每个字段。

### 6.1 市场分析：BULL、BEAR 或 RANGE

每次买入（现货）或开仓（永续合约）之前，机器人会基于**该交易对自身**的K线对其进行分析：

1. 它获取该交易对 **K线周期**（留空 = 全局 **K线周期** 设置）的最近 **获取的K线数量** 根K线（设置项 `LIMIT`）。
2. **当前价格**为最近一根K线的收盘价。
3. 它计算收盘价的三条移动平均线：**MA4**、**MA8** 和 **MA12**（其K线数量在**设置 → 市场分析**中设置）。
4. 它按以下顺序判断市场类型：
   - 如果 MA12 走平，则为 **RANGE**：在最近 **MA12 检查周期数** 内，MA12 的最低值与最高值之间的变动不超过 **MA12 RANGE 阈值（%）**；
   - 否则，如果 MA4 > MA8 > MA12，则为 **BULL**；
   - 否则，如果 MA4 < MA8 < MA12，则为 **BEAR**；
   - 否则为 **RANGE**。
5. 它还会计算**区间**：最近 **RANGE - 区间周期数** 根K线中的最高收盘价和最低收盘价。其幅度为最高价 − 最低价。

随后，每个交易对使用**其自身针对所检测到的市场类型的设置**（该交易对的 BULL、BEAR 或 RANGE 区块）。如果分析失败（无法连接 Hyperliquid），则不会下任何订单，机器人会在下一轮重试。

### 6.2 现货周期详解

一个现货周期由一次买入和随后对相同数量的一次卖出组成。

1. **何时。** 机器人每隔 **买入循环短暂停（分钟）** 检查每个已启用的现货交易对。满足以下条件时会尝试买入：
   - 该交易对不处于暂停状态（见第 6 步）；
   - 自该交易对上一次尝试以来，至少已经过该交易对三个 **买入间隔（分钟）** 值（BULL、BEAR、RANGE）中**最小**的那个，无论当前市场如何。机器人启动后的第一次尝试会等待 **首次买入前延迟（分钟）**。
2. **是否允许？** 买入必须在全局（**启用买入（全局）**）**以及**该交易对当前市场的区块中（**已启用买入**）均已启用。否则，该次尝试会被计入，但不会下任何订单。
3. **价格。** 设 *P* = 当前价格：
   - 买入价 = *P* + **买入偏移**；目标卖出价 = *P* + **卖出偏移**；
   - **偏移单位** 为 `abs` 时，偏移以 USDC 表示；为 `pct` 时，以 *P* 的 % 表示；
   - **在 RANGE 市场中**，偏移是**动态**的：买入 = *P* − *d*，卖出 = *P* + *d*，其中 *d* = 区间幅度 × **RANGE - 区间使用百分比** / 100 / 2。仅当无法计算区间（幅度为 0）时，才使用该交易对的 RANGE 静态偏移。
4. **数量。** 金额 = **USDC 余额的 %** × **可用** USDC（未被挂单占用的部分）。数量 = 金额 / 买入价，按该交易对的数量步长**向下**取整。如果订单金额低于 **最小订单金额（USDC）**（至少 10 USDC，Hyperliquid 的最低要求），买入将被拒绝，日志中显示“Value too low”。
5. **下单。** 以买入价挂出限价买单。该周期在仪表盘上显示为 **待买入**，目标卖出价已被记录。
6. **暂停。** 每次尝试之后，无论是否下单，该交易对都会等待当前市场区块的 **尝试后暂停（分钟）**。
7. **买单成交。** 机器人通过 Hyperliquid 历史记录得知成交，该历史记录每隔 **Hyperliquid 获取间隔（分钟）** 获取一次。周期变为 **待卖出**。部分成交且仍挂着的买单保持 **待买入**。
8. **卖出。** 卖出循环（每隔 **卖出循环间隔（秒）**）以**第 3 步记录的目标卖出价**挂出限价卖单。它卖出实际收到的数量：Hyperliquid 以所买入的代币收取买入手续费，因此机器人卖出的是买入数量减去该手续费，并按数量步长向下取整。少量余数可能留在您的 wallet 中；之后的周期会在余额允许时将其卖出。
   - 卖出价不会重新计算。如果市场价格已经高于该价格，卖单会立即以市场价格成交（优于预期）。
   - 如果余额不足，机器人会重试；尝试 3 次后，该问题会作为**错误**写入日志。
9. **卖单成交。** 周期变为 **已完成**。利润按实际卖出价格、数量和实际手续费计算：卖出数量 × （卖出价 − 买入价） − 买入手续费 − 卖出手续费。

**已启用卖出** 开关目前不起作用：买单一旦成交，总会挂出对应的卖单。

**计算示例（RANGE）。** 当前价格 85,000；最近 20 根K线中最高收盘价为 85,200，最低为 84,770：幅度为 430。**RANGE - 区间使用百分比** = 75 时：*d* = 430 × 75 / 100 / 2 = 161.25。买入价 85,000 − 161.25 = 84,838.75；目标卖出价 85,000 + 161.25 = 85,161.25。**USDC 余额的 %** = 5 且可用 USDC 为 400 时：20 USDC，即 20 / 84,838.75 = 0.0002357 个基础代币，按该交易对的数量步长向下取整。

### 6.3 永续合约周期详解

一个永续合约周期由一次开仓（做多或做空）以及随后通过止盈、止损或平仓的一次退出组成。

1. **何时。** 规则与现货相同：每隔 **买入循环短暂停（分钟）** 检查每个已启用的永续合约交易对；每次尝试后暂停（当前市场区块的 **尝试后暂停（分钟）**），并采用三个 **开仓间隔（分钟）** 中的最小值。
2. **在任何开仓之前，每一轮**，机器人都会将当前的 **方向** 应用于该交易对上已打开的周期：
   - 方向 **none**：尚未成交的开仓单被取消；已有持仓按照 **方向设置为“none”但仍有持仓** 处理（`keep_tp_sl` = 保留止盈和止损；`close_market` / `close_limit` = 平仓）；
   - 方向与已打开的周期**相反**（例如持有多头时方向为 `short`）：尚未成交的开仓单被取消，已有持仓按照 **反转时平仓** 平仓（`market` = 市价单；`limit` = 以当前价格挂限价单）。
3. **哪一方向。** `long` 或 `short`：即该方向。`none`：不开仓。`both`：按照 **“both”方向的规则**：
   - `first_filled`：同时挂出做多开仓单和做空开仓单；先成交的一方取消另一方；
   - `range_position`：价格位于区间下半部分时做多，位于上半部分时做空；非 RANGE 市场时不开仓；
   - `alternate`：与该交易对上一周期相反的方向。
4. **资金费率过滤。** 资金费率高于 +**资金费率阈值（%）** 时不做多；低于 −阈值时不做空。如果无法获取资金费率，则不开仓。
5. **杠杆与保证金。** 如有需要，机器人会在开仓前在 Hyperliquid 上设置该交易对的 **杠杆** 和 **保证金模式**。
6. **价格与仓位大小。** 设 *P* = 当前价格：开仓价 = *P* + 该方向的开仓偏移，止盈价 = *P* + 该方向的止盈偏移（根据 **偏移单位** 以 USDC 或 % 表示）。使用的保证金 = **可用保证金的 %** × 可用保证金；仓位大小 = 保证金 × 杠杆 / 开仓价，向下取整。
7. **开仓。** 以开仓价挂出限价单。成交后，机器人以记录的价格挂出**止盈**单（限价，只减仓），并在距实际开仓价 **止损（开仓价格的 %）** 处挂出**止损**单（止损市价，只减仓）。
8. **退出。** 当止盈、止损或平仓单成交时，周期结束。市价单和止损市价单可接受的偏差最多为 **市价单滑点（%）**。

请在 **🟣 永续合约周期** 页面跟踪永续合约周期。

### 6.4 交易中的交易对页面

**🧩 交易中的交易对** 页面列出为机器人配置的交易对。

- **添加交易对**：在 **🌐 Hyperliquid 交易对** 页面上，点击该交易对所在行的 **添加**。新交易对处于 **已禁用** 状态；其现货设置会以 **设置** 页面中 BULL / BEAR / RANGE 的默认值预先填写。永续合约设置必须手动填写。
- **编辑**：打开该交易对的设置：先是通用部分，然后每种市场类型（BULL、BEAR、RANGE）各一个区块。**保存** 会检查每个值；错误的字段会被高亮显示。
- **配置** 列：**完整**，或 **待完善** 的字段数量。交易对只有在配置完整时才能启用。
- **启用 / 禁用**：只有已启用且配置完整的交易对才会被交易。只有以 USDC 计价的现货交易对才能启用。已禁用的交易对不会再开新仓，但**其已打开的周期会继续，直到结束**。
- **删除**：仅当该交易对没有进行中的周期时才可删除。请先禁用它，并等待其周期结束。
- 更改会在相关循环的下一轮生效，无需重启。

**偏移** — 买入价或开仓价 = 当前价格 + 偏移；卖出价或止盈价 = 当前价格 + 偏移。负偏移表示低于当前价格。

#### 现货交易对设置

通用部分：

| 字段 | 含义 |
|---|---|
| 偏移单位 | `abs` = 偏移以 USDC 表示；`pct` = 偏移以当前价格的 % 表示 |
| K线周期 | 该交易对市场分析所用的K线；留空 = 全局 **K线周期** |
| RANGE - 区间使用百分比 | RANGE 中的动态偏移 = ±（区间幅度 × 该 %）/ 2 |

BULL、BEAR、RANGE 各一个区块：

| 字段 | 含义 |
|---|---|
| 已启用买入 | 检测到该市场类型时允许买入 |
| 已启用卖出 | 目前不起作用：卖单总会挂出 |
| 买入偏移 | 买入价 = 当前价格 + 该偏移（通常为负）；在 RANGE 中由动态偏移代替 |
| 卖出偏移 | 目标卖出价 = 当前价格 + 该偏移；在 RANGE 中由动态偏移代替 |
| USDC 余额的 % | 每次买入所使用的可用 USDC 比例 |
| 尝试后暂停（分钟） | 在该市场中每次买入尝试后的等待时间 |
| 买入间隔（分钟） | 两次买入尝试之间的最短时间；采用三个区块中的最小值 |

#### 永续合约交易对设置

通用部分：

| 字段 | 含义 |
|---|---|
| 偏移单位 | `abs` = USDC；`pct` = 当前价格的 % |
| K线周期 | 与现货相同 |
| 杠杆 | 不超过该资产的最大杠杆 |
| 保证金模式 | `cross` 或 `isolated`（部分资产要求 `isolated`） |
| 止损（开仓价格的 %） | 在实际开仓价的该 % 处挂出止损市价单 |
| 资金费率阈值（%） | 资金费率 > +阈值时不做多；资金费率 < −阈值时不做空 |
| 市价单滑点（%） | 市价单和止损市价单可接受的最大偏差 |
| “both”方向的规则 | `first_filled`、`range_position` 或 `alternate`（见 6.3）；只要有区块使用 `both` 即为必填 |
| 反转时平仓 | `market` 或 `limit` |
| 方向设置为“none”但仍有持仓 | `keep_tp_sl`、`close_market` 或 `close_limit` |

BULL、BEAR、RANGE 各一个区块：

| 字段 | 含义 |
|---|---|
| 方向 | `long`、`short`、`both` 或 `none`（不开仓） |
| 做多开仓偏移 / 做多止盈偏移 | 止盈必须高于开仓 |
| 做空开仓偏移 / 做空止盈偏移 | 止盈必须低于开仓 |
| 可用保证金的 % | 每次开仓所使用的可用保证金比例，做多和做空相同 |

## 16. 在 Flux 上运行 HL-Spot

[Flux](https://runonflux.com) 是一个去中心化云：它在由第三方运营的服务器（节点）上出租容器。HL-Spot 可以在那里全天候运行，无需您的电脑。Flux 独立于 HL-Spot，费用支付给 Flux。

### 您在 Flux 上的 API wallet 密钥：请先阅读

在 Flux 上，机器人的数据（`/data`：加密的 API wallet 密钥**以及**用于解密它的 `secret.key` 文件）存放在他人运营的服务器上，并复制到 3 个节点。部署时由您选择应用类型：

- **Enterprise 应用**（ArcaneOS 节点）——推荐：Flux 声明节点运营者无法访问应用数据（磁盘加密、root 访问受限），且环境变量保持私密。
- **普通应用**：节点运营者可以读取 `/data`，因而可以读取您的 API wallet 密钥；环境变量（包括首次启动代码）任何人都可以读取。API wallet 无法提取您的资金，但持有其密钥的人可以在您的账户上交易。风险自负。

无论哪种类型，您都可以随时在 Hyperliquid 上撤销该 API wallet（第 3 节）。

### 应用设置

| Flux 字段 | 值 |
|---|---|
| 镜像 | `olivier1246/hl-spot:1.0.2` |
| 端口和容器端口 | `60000` |
| 容器数据 | `g:/data`（**必填**） |
| CPU | 0.2 |
| RAM | 300 MB（如果应用因内存不足而重启，请调高） |
| SSD | 3 GB |
| 实例数 | 3（Flux 最低要求） |
| 环境变量 | `HL_SPOT_SETUP_CODE=<您的代码>`（**必填**），`TZ=Europe/Paris`（可选） |

- `g:/data`：只有**一个**实例运行机器人；另外 2 个保存数据的同步副本，在它停止时接替。切勿使用其他值：否则机器人会同时在 3 台机器上运行，每个订单下 3 次。
- `HL_SPOT_SETUP_CODE`：至少 12 个字符的代码，且不同于您的密码。没有它，任何找到应用地址的人都可能抢先创建账户。

### 在 Flux 上首次启动

1. 打开 Flux 为该应用提供的 **https** 地址。
2. 按照第 5 节操作，并在**首次启动代码**框中输入您的代码。
3. 使用装有钱包扩展的浏览器：机器人用它签署消息。

### 须知

- 安装随数据而行：机器人迁移到另一个节点时，不算作更换安装（第 10 节）。
- 迁移后，机器人从同步副本重新启动：请在 Hyperliquid 上检查您的未成交订单。
- **更新**：在 Flux 的应用设置中将镜像替换为新版本。
- 该页面可从互联网访问：受您的密码保护。请选择强密码。
