# HL-Spot — 用户指南

版本 1.0.2

HL-Spot 是一款用于 **Hyperliquid** 的交易机器人：支持 spot 和永续合约（perp）市场、多个交易对、自动和手动下单。它运行**在您自己的电脑上**（Windows、Linux 或 Docker），您可以通过网页浏览器对其进行控制。

> **网站**：https://hlspot.com
> **下载**：https://github.com/HL-Spot-Bot/HL-Spot-Bot
> **支持**：HL-spot@cmails.eu

---

## 1. 开始之前

您需要：

- 一台搭载 64 位 x86 处理器（x86_64）并运行 **Windows** 或 **Linux** 的电脑，或任何装有 **Docker** 的机器；
- 或者一个 **Flux** 账户，以便在云端运行（第 16 节）；
- 一个有资金的 **Hyperliquid** 账户（您的主 wallet）；
- 一个能够用您的主 wallet 地址“**签名消息**”的 wallet。浏览器扩展（MetaMask、Rabby…）最为简单：机器人会为您打开它。其他任何 wallet 也可以通过复制粘贴的方式使用；
- 互联网连接。

## 2. 安全：您必须了解的事项

- HL-Spot 只接受 Hyperliquid 的 **API wallet** 密钥。**切勿输入您主 wallet 的私钥。** API wallet 可以代您交易，但无法提取您的资金。
- API wallet 密钥在您的电脑上是**加密**存储的。它**绝不会被发送**到许可证服务器。
- 您的主 wallet 仅用于**签名消息**（创建账户、忘记密码、BTC 地址、删除账户）。签名消息不是交易：它不产生任何费用，也不会转移任何资金。
- 机器人的网页受您的密码保护。建议在机器人所在的机器上使用（`http://localhost:60000`）：从您网络中的其他机器访问时，页面是不加密的（见第 15 节）。

## 3. 创建您的 Hyperliquid API wallet

1. 前往 **https://app.hyperliquid.xyz/API** 并连接您的主 wallet。
2. 为 API wallet 命名，然后生成它。
3. **复制显示的私钥**并妥善保管：Hyperliquid 只显示一次。
4. 授权该 API wallet（使用您的主 wallet 签名）。
5. 记下 Hyperliquid 显示的 API wallet **到期日期**。

您将在 HL-Spot 中输入：您的**主 wallet 地址**（0x…）和 **API wallet 私钥**。

## 4. 安装 HL-Spot

从 https://github.com/HL-Spot-Bot/HL-Spot-Bot 下载适用于您系统的文件及其 `.sha256` 文件。`.sha256` 文件可用于检查下载的文件是否完整。

### Windows

1. 解压 `HL-Spot-1.0.2-prod-windows-x64.zip`。
2. 在解压后的文件夹中，运行 **`HL-Spot.exe`**。会打开一个控制台窗口：在机器人运行期间请保持其打开。
3. 在浏览器中打开 **http://localhost:60000**。

### Linux（Ubuntu 22.04、24.04、26.04、Debian 12 或更新版本）

```
unzip HL-Spot-1.0.2-prod-linux-x64.zip
cd HL-Spot-1.0.2-prod-linux-x64
./hl-spot
```

然后在浏览器中打开 **http://localhost:60000**。

### Docker

```
docker load -i HL-Spot-1.0.2-prod-docker-x64.tar.gz
docker run -d --name hl-spot --restart unless-stopped -p 60000:60000 \
       -e TZ=Europe/Paris -v hl-spot-data:/data hl-spot:1.0.2
```

- `-p 60000:60000` 是访问网页所必需的。
- `TZ` 设置时区（省略时为 UTC）。
- 您的数据保存在 `hl-spot-data` 卷中，即使删除容器或更新镜像也不会丢失。
- `docker stop hl-spot` 可以干净地停止机器人。

然后打开 **http://localhost:60000**（或 `http://<machine address>:60000`）。

### 您的数据保存位置

您的数据（设置、加密的密钥、数据库、日志）保存在**程序之外**：

| 系统 | 文件夹 |
|---|---|
| Windows | `%LOCALAPPDATA%\HL-Spot` |
| Linux | `~/.local/share/hl-spot` |
| Docker | `/data` 卷 |

重新安装或更新程序绝不会影响这些数据。

## 5. 首次启动

第一个页面是**首次启动**。请选择：

- 如果您是新用户，选择**创建账户**；
- 如果您已有 HL-Spot 账户（新电脑、重新安装），选择**我已有账户**。

### 创建账户

1. **钱包地址**：您的主 wallet 地址（0x…）。
2. **API wallet 私钥**：第 3 节中复制的密钥。系统会先通过 Hyperliquid 对其进行验证。
3. **密码**：至少 8 个字符，包含一个大写字母、一个小写字母、一个数字和一个特殊字符。它同时保护您的 HL-Spot 账户和机器人的网页。
4. **主钱包签名**：
   - **用我的钱包签名**：机器人会打开您的 wallet 扩展；请核对地址并确认签名；
   - 或**获取待签名消息**：将消息原样复制到您的 wallet 中，签名后粘贴签名（0x…）。该消息在 15 分钟内有效。
5. 点击**创建账户**。

您的 **7 天免费试用**随即开始。每个 wallet、每次安装仅授予一次。您的 Hyperliquid 账户验证通过后即开始交易。

### 我已有账户

输入您的钱包地址和密码。本次安装将被注册，之前的安装将被释放（**每 30 天只能更换一次安装**）。

## 6. 使用机器人

顶部菜单可访问以下页面：

| 页面 | 用途 |
|---|---|
| 📊 仪表盘 | 余额、市场状态、各交易对的状态 |
| 📈 统计 | 现货和永续合约周期结果（按期间） |
| 🧩 交易中的交易对 | 为机器人配置的现货和永续合约交易对 |
| 🟣 永续合约周期 | 永续合约交易对的开仓、止盈、止损和平仓 |
| 🖐️ 手动下单 | 手动下单；之后机器人会像其他订单一样跟踪该周期 |
| 🌐 Hyperliquid 交易对 | Hyperliquid 现货和永续合约交易对列表 |
| ⚙️ 设置 | 所有设置（无需重启即可生效，端口和监听地址除外） |
| 📝 日志 | 错误（以及启用后的警告） |
| 🔑 Hyperliquid 账户 | wallet、API wallet 密钥、到期日期 |
| 📜 许可证 | 许可证、订阅、付款、安装、删除账户 |

只有在**您的 Hyperliquid 账户已验证**且**您的许可证有效**时，机器人才会进行交易。没有有效许可证时，只能使用 Hyperliquid 账户和许可证页面。

当机器人停止交易时（许可证到期、API wallet 过期或被拒绝），它**不会处理已经挂出的订单和已开的仓位**：这些由您自行负责。

## 7. 许可证与订阅

### 价格

| 订阅 | 价格 |
|---|---|
| 7 天 | 2 $ |
| 30 天 | 6 $ |

所付费的时长会追加到您当前许可证的结束日期之后（如果许可证已到期，则从付款日期开始计算）。

### 如何付款

在**许可证**页面的**订阅与付款**区块中：

1. 选择订阅、代币和网络；
2. 机器人会显示**确切金额**、**收款地址**以及您必须**从中付款**的地址。该金额在 **1 小时**内有效（如果价格波动超过 10 %，有效时间会更短）；
3. **从您 HL-Spot 账户的 wallet**、在**该网络**上发送**确切的金额**；
4. 付款会被自动识别（视网络而定，需要几分钟），许可证随即延长。

可用的代币和网络以许可证页面上显示的为准。

**规则 — 付款前请务必阅读：**

- 支付**确切**的所需金额，不多也不少；**网络手续费由您承担**；
- **从您账户的 wallet** 付款（BTC：从您已声明的 BTC 地址付款）；
- 在显示的网络上、在金额有效期内付款；
- 不符合这些规则的付款（未知地址、金额不同、其他网络、超过有效期）**将会丢失：不予退款**。

### 使用 BTC 付款

首次使用 BTC 付款之前，请在许可证页面上声明您的 **BTC 地址**（通过主 wallet 签名进行证明）。只有**从该 BTC 地址**发出的付款才会被识别：在您的 BTC wallet 中，选择该地址作为付款来源（“coin control”）。

### 许可证检查

- 许可证**每 6 小时**与服务器核对一次。
- 如果无法连接服务器，机器人会继续运行，直到已知的许可证结束日期。
- **到期前 24 小时**：在网页上和通过 Telegram 发出警告。
- 到期后：**24 小时宽限期**（交易继续，并显示警告），之后交易停止。
- 请勿将电脑时钟往回调：时钟回调超过 5 分钟会导致交易停止，直到下一次检查成功。

## 8. API wallet：到期与更换

- **Hyperliquid 账户**页面会显示您 API wallet 的到期日期。如有需要，您也可以自行输入。
- 在**最后 7 天**内：网页上会显示横幅，并且每天发送一条 Telegram 消息。
- 到期日当天，交易停止。请创建新的 API wallet（第 3 节），并在 **Hyperliquid 账户**页面输入其密钥：无需重启程序，交易即可恢复。
- 新密钥必须属于**同一个主 wallet**：钱包地址无法更改。
- 机器人在启动时以及每 24 小时会通过 Hyperliquid 检查该 API wallet 是否仍属于您的 wallet。

## 9. Telegram 通知

在**设置 → Telegram 通知**中：

1. 使用 **@BotFather** 创建一个 Telegram 机器人并复制其 token；
2. 获取您的 chat ID（例如通过 **@userinfobot**）；
3. 输入 token 和 chat ID，然后启用通知并选择要接收的消息（已下单、买入成交、已完成的周期、错误、每日汇总）。

## 10. 在另一台电脑上使用 HL-Spot

在新电脑上安装机器人，并在首次启动时选择**我已有账户**。旧的安装将被释放。**每 30 天只能更换一次**。许可证页面会显示下次可更换的日期。

## 11. 忘记密码

在登录页面，点击**忘记密码？**。通过**主 wallet 签名**证明您拥有该 wallet，然后设置新密码。

## 12. 日志

**📝 日志**页面显示机器人记录的错误（如果启用了**设置 → 日志文件 → 记录警告**，还会显示警告）。文件大小限制为 1 MB：最旧的条目会被删除。您可以筛选、下载文件（对支持很有用）以及清空日志。

## 13. 删除您的账户

**许可证**页面，**🗑️ 删除我的账户**：密码 + 主 wallet 签名。

- 您的 HL-Spot 账户将被**永久**删除。
- 剩余的许可证时长将**丢失且不予退款**。
- 该 wallet **不会**再次获得免费试用。
- 在这台电脑上，钱包地址、API wallet 密钥和密码会被清除；交易历史会被保留。

## 14. 更新与备份

- **更新**：安装新版本（解压，或加载新的 Docker 镜像）；您的数据会被保留（第 4 节）。
- **备份**：复制数据文件夹（第 4 节）。`.env` 文件和 `secret.key` 文件必须**一起**备份：没有 `secret.key`，就无法读取 `.env` 和数据库中的加密值。如果丢失了 `secret.key`，这些值（API wallet 密钥、Telegram token…）必须重新输入。

## 15. 从另一台机器访问

默认情况下，网页在所有网络接口上监听，端口为 **60000**（**设置 → 网页界面**，重启后生效）。从您网络中的另一台机器访问：`http://<bot machine address>:60000`。

在网络上，页面是**不加密**的：最好在机器人所在的机器上输入您的 API wallet 密钥和密码。切勿将端口 60000 直接暴露到互联网。

## 16. 在 Flux 上运行 HL-Spot

[Flux](https://runonflux.com) 是一个去中心化云：它在由第三方运营的服务器（节点）上出租容器。HL-Spot 可以在那里全天候运行，无需您的电脑。Flux 独立于 HL-Spot，费用支付给 Flux。

### 您在 Flux 上的 API wallet 密钥：请先阅读

在 Flux 上，机器人的数据（`/data`：加密的 API wallet 密钥**以及**用于解密它的 `secret.key` 文件）存放在他人运营的服务器上，并复制到 3 个节点。部署时由您选择应用类型：

- **Enterprise 应用**（ArcaneOS 节点）——推荐：Flux 声明节点运营者无法访问应用数据（磁盘加密、root 访问受限），且环境变量保持私密。
- **普通应用**：节点运营者可以读取 `/data`，因而可以读取您的 API wallet 密钥；环境变量（包括首次启动代码）任何人都可以读取。API wallet 无法提取您的资金，但持有其密钥的人可以在您的账户上交易。风险自负。

无论哪种类型，您都可以随时在 Hyperliquid 上撤销该 API wallet（第 3 节）。

### 应用设置

| Flux 字段 | 值 |
|---|---|
| 镜像 | `olivier1246/hl-spot:1.0.2` |
| 端口和容器端口 | `60000` |
| 容器数据 | `g:/data`（**必填**） |
| CPU | 0.2 |
| RAM | 300 MB（如果应用因内存不足而重启，请调高） |
| SSD | 3 GB |
| 实例数 | 3（Flux 最低要求） |
| 环境变量 | `HL_SPOT_SETUP_CODE=<您的代码>`（**必填**），`TZ=Europe/Paris`（可选） |

- `g:/data`：只有**一个**实例运行机器人；另外 2 个保存数据的同步副本，在它停止时接替。切勿使用其他值：否则机器人会同时在 3 台机器上运行，每个订单下 3 次。
- `HL_SPOT_SETUP_CODE`：至少 12 个字符的代码，且不同于您的密码。没有它，任何找到应用地址的人都可能抢先创建账户。

### 在 Flux 上首次启动

1. 打开 Flux 为该应用提供的 **https** 地址。
2. 按照第 5 节操作，并在**首次启动代码**框中输入您的代码。
3. 使用装有钱包扩展的浏览器：机器人用它签署消息。

### 须知

- 安装随数据而行：机器人迁移到另一个节点时，不算作更换安装（第 10 节）。
- 迁移后，机器人从同步副本重新启动：请在 Hyperliquid 上检查您的未成交订单。
- **更新**：在 Flux 的应用设置中将镜像替换为新版本。
- 该页面可从互联网访问：受您的密码保护。请选择强密码。
